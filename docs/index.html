Runnable local assistant
This package calls an AI model with your instructions and returns a real draft or analysis. Python 3.10+, an OpenAI API key, and a model available to your API account are required. API charges are separate. App actions and background scheduling are not included in this version.

1. Download your files

Your configuration contains the instructions you just created. The runner uses them to process your input.

2. Add your input

Save a request or source notes in a file named input.txt, next to both downloads.

3. Run the assistant

Set OPENAI_API_KEY and OPENAI_MODEL as environment variables on your computer. Keep your key out of downloaded JSON and website forms.

python agent.py agent.json input.txt

The result appears in your terminal and is saved in a local run database. Repeating identical input reuses the saved result without another model call.

Want to run it from this website?

Hosted execution is not connected yet. It requires account storage, a server, and model billing. You cannot launch a hosted agent or purchase a subscription here yet.

        A little guidance

        From plan to practice.

        What can the assistant do today?

        AgentSketch now exports a runnable local AI assistant. Supply your model API credentials on your computer and run it against a text file to generate a draft or analysis. Hosted execution, connected app actions, and scheduled agents still require backend setup.

        How should I use my blueprint?

        Start with the setup guide. Create a small fictional dataset and a manual version of the workflow. Copy the agent prompt into your assistant, confirm every draft, and connect automation only after your manual tests pass. Download the blueprint to keep a copy.

        Is this free? Do I need other tools?

        This website is free and uses local rules instead of a paid AI API. The suggested third-party tools have their own plans and limits. Check current quotas before enabling automation. You can start manually with tools you already use.

        Where are my answers stored?

        Your answers stay in this browser tab unless you select “Save my draft on this device.” That option stores your answers and checklist in this browser’s local storage until you reset the workspace. Downloads create files on your device. No analytics, accounts, or external AI calls are used.

        What should I test before using real information?

        Try a normal input, missing details, repeated input, an unexpected format, and a tool failure. Check that duplicates are skipped, uncertain cases stop for review, failures are logged, and nothing is sent or changed without approval. The sample area demonstrates only the local planning rules.
